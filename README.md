# Финконтроль

Учёт личных финансов на одной HTML-странице. Без бэкенда и аккаунтов: данные
лежат в `localStorage` браузера, бэкап — файлом JSON. Ставится на экран «Домой»
как приложение и работает без интернета.

## Что умеет

- **Счета.** Наличные, банк и кредитка. Кредитка хранится как счёт с
  отрицательным балансом, поэтому трата по ней растит долг, а перевод на неё —
  гасит.
- **Операции в два тапа.** Приложение само находит в истории самые частые
  сочетания «категория + сумма + счёт» и показывает их кнопками: тап по виду
  операции, тап по кнопке — записано. Остальное вводится своей цифровой
  клавиатурой, чтобы системная не дёргала страницу.
- **Долги.** Кто, сколько, до какого числа. Отметка «вернул» спрашивает счёт
  поступления и сама заводит доход.
- **История.** По дням, с фильтром и правкой. Балансы не хранятся, а каждый раз
  пересчитываются из журнала операций — после правки или удаления разойтись
  они не могут.
- **Главный экран.** Чистый капитал, предупреждение о запасе наличных, обратный
  отсчёт до погашения кредитки, недельный лимит и лестница целей с прогнозом дат
  по темпу накоплений за последние четыре недели.

## Как пользоваться

Откройте страницу, зайдите в «Настройки» и укажите стартовые балансы. Там же
настраиваются пороги, число месяца для погашения, цели, источники дохода и
категории трат.

**Установка на iPhone.** Откройте сайт в Safari → «Поделиться» → «На экран
«Домой»».

**Бэкап.** «Настройки» → «Скачать файл» (или «Поделиться» / «Скопировать JSON»).
Восстановление — там же, файлом или вставкой текста; перед заменой спрашивается
подтверждение, а отменить импорт можно одной кнопкой сразу после него.

## Разработка

```sh
npm test       # тесты расчётов
npm run serve  # локальный сервер на http://localhost:8765
npm run icons  # перегенерировать иконки PWA
```

Расчёты лежат в `index.html` в блоке между маркерами `CORE:START` и `CORE:END`
и не обращаются к DOM. Тест вырезает этот блок из файла и исполняет его в
`node:vm` — поэтому приложение остаётся одной страницей, а логика при этом
проверяется.

Дизайн-документ: [`docs/superpowers/specs/2026-10-03-fincontrol-design.md`](docs/superpowers/specs/2026-10-03-fincontrol-design.md).

## Приватность

Репозиторий публичный, данные — нет. Суммы, операции и долги никогда не
покидают устройство: сервера у приложения нет, аналитики и внешних запросов
тоже. Единственное обращение наружу — шрифты Google Fonts при первой загрузке;
дальше они берутся из кеша, и приложение работает офлайн.
